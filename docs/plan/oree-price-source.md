# Джерело цін ОРЕЕ

Планувальник використовує офіційне вивантаження ОРЕЕ зі сторінки [Ринок на добу наперед](https://www.oree.com.ua/index.php/pricectr). Файл отримується POST-запитом до `/index.php/pricectr/get_file`:

- `price_date`: `MM.yyyy` локального місяця;
- `market_type`: `DAM` (РДН) або `IDM`;
- `zone`: `IPS` (ОЕС України; для нових періодів сайт примусово використовує IPS).

Відповідь — XLS (`application/vnd.ms-excel`). `OreePriceFileSource` читає погодинний ряд, вимагає рівно 23/24/25 значень для DST-горизонту, відхиляє пропуски та неповні колонки й повертає `PriceSeries` у `UAH/MWh` з джерелом `OREE`.

ENTSO-E більше не є джерелом планувальника. До запису в Deye застосовуються ті самі UPS/SOC/потужнісні та feature-flag перевірки.
