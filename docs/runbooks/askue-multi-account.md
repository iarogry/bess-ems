# ASKUE: окремі облікові записи для площадок

Приклад конфігурації: `config/examples/askue-accounts.json`. Це шаблон, реальних секретів у ньому немає.

Кожний увімкнений елемент `Askue:Accounts` має власні `Username`, `Password`, `SiteId`, `BaseUrl`, `PointIds`, часовий пояс та інтервал опитування. `SiteId` обов’язковий і унікальний серед увімкнених акаунтів. Дані записуються з цим SiteId; однакові номери лічильників різних акаунтів не змішуються.

Для додавання площадки створіть новий ключ акаунта, задайте явний SiteId, його секрети та потрібні лічильники, увімкніть акаунт і перезапустіть застосунок. Секрети можна передати змінними середовища:

```text
Askue__Accounts__another_site__Enabled=true
Askue__Accounts__another_site__SiteId=site-another
Askue__Accounts__another_site__Username=<login>
Askue__Accounts__another_site__Password=<password>
Askue__Accounts__another_site__BaseUrl=https://askue.net/api/askue/v1/json/
Askue__Accounts__another_site__PointIds=101,102
```

Порожній PointIds означає всі доступні цьому акаунту точки. Якщо заданий номер недоступний акаунту, опитування завершується помилкою, а не мовчазним пропуском. Два акаунти для одного SiteId наразі не підтримуються: об’єднання потребуватиме окремих правил уникнення дублювання.

Кожний акаунт має незалежний фоновий цикл та HTTP-клієнт. Помилка авторизації чи мережі одного акаунта не зупиняє інші. Вимкнені акаунти не опитуються. Наявність Accounts переводить ASKUE в новий режим; кореневі Username/Password не успадковуються. Без Accounts стара конфігурація одного акаунта продовжує працювати.

`GET /sites/askue/status` повертає `account_id`, `site_id`, `state`, `last_attempt_at`, `last_success_at`, `last_imported_readings`, `error_code`. Логіни й паролі не повертаються. Після невдалого опитування зберігаються час і кількість записів останнього успіху. Статуси зберігаються в пам’яті та скидаються під час перезапуску. Інтерфейс введення секретів у браузері не додавався.

Це збір інтервальних даних АСКУЕ. Він не перетворює енергію за інтервал на миттєву потужність дашборда і не визначає ролі/коефіцієнти лічильників автоматично. Для балансів потрібна окрема перевірена карта лічильників площадки. Жодних команд керування цей конектор не надсилає.
