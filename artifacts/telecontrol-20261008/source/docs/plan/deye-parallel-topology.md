# Deye: паралельна топологія та параметри моделювання

- батарейний банк: **314 А·год** номінально;
- два інвертори працюють паралельно, сумарна межа заряду — **160 кВт**, сумарна межа розряду — **160 кВт**;
- один інвертор визначений як **master**;
- усі налаштування й команди Deye надсилаються тільки master;
- slave не отримує окремих команд: його параметри синхронізуються master через Modbus-паралельний зв'язок.

Планувальник моделює один агрегований актив `BESS-parallel`, а не два незалежні активи. Перед записом перевіряється, що цільовий serial — master; команди для slave блокуються.

Напруга, SOC та ємність не задаються вручну: джерелом істини є BMS master через Deye `device/latest`. Використовуються метрики `BMSVoltage`, `BMSSOC` та `BatteryRatedCapacity` (для другого BMS — відповідні `BMS2*`, якщо він підключений). Загальні `batterySOC`/`battCapacity` використовуються лише як діагностичний fallback і не можуть керувати планом. Для кожного циклу перевіряється свіжість вимірювання та діапазони напруги/SOC.

Для перерахунку А·год у кВт·год використовується фактично зчитана напруга батарейної шини та ємність BMS:

`capacity_kwh = 314 Ah × nominal_voltage_v / 1000`.

Якщо `BMSVoltage`, `BMSSOC` або `BatteryRatedCapacity` відсутні/застарілі, моделювання та будь-які команди блокуються.
